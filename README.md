## 📝 Deskripsi

Portofolio ini dibangun menggunakan **ReactJS** untuk struktur komponen yang modular dan **Tailwind CSS** untuk desain antarmuka yang modern, responsif, dan cepat. Situs ini menggabungkan pemahaman mendalam tentang infrastruktur IT dengan kemampuan membangun solusi web yang fungsional, interaktif, dan optimal di berbagai perangkat (mobile-friendly).

### Fitur Utama:
- **Desain Modern & Responsif:** Menggunakan utilitas kelas Tailwind CSS.
- **Navigasi Interaktif:** Menu navigasi yang halus untuk berpindah antar bagian (Home, About, Skills, Projects, Contact).
- **Komponen Modular:** Dibangun dengan arsitektur komponen React yang bersih dan mudah dirawat.

## 📋 Persyaratan (Requirements)

Sebelum menjalankan proyek ini di lingkungan lokal Anda, pastikan Anda telah menginstal perangkat lunak berikut:

- [Node.js](https://nodejs.org/) (Versi LTS direkomendasikan, minimal v16+)
- [npm](https://www.npmjs.com/) (Biasanya otomatis terinstal bersama Node.js) atau [yarn](https://yarnpkg.com/)
- Peramban web modern (Chrome, Edge, Firefox, atau Safari)

## ⚙️ Instalasi (Installation)

Ikuti langkah-langkah di bawah ini untuk menyalin dan menjalankan proyek ini secara lokal:

1. **Klon repositori ini:**
   ```bash
   git clone https://github.com/nabrashhh/portofolio-react.git
   ```

2. **Masuk ke direktori proyek:**
   ```bash
   cd portofolio-react
   ```

3. **Instal semua dependensi yang diperlukan:**
   ```bash
   npm install
   # atau jika menggunakan yarn:
   yarn install
   ```

## 🚀 Penggunaan (Usage)

### Menjalankan Server Pengembangan Lokal
Untuk melihat perubahan secara langsung (development mode), jalankan perintah berikut:
```bash
npm run dev
# atau jika menggunakan yarn:
yarn dev
```
Setelah berhasil berjalan, buka browser Anda dan akses alamat yang tertera di terminal (biasanya `http://localhost:5173` atau `http://localhost:3000`).

### Membuat Build Produksi
Untuk mengompilasi dan mengoptimalkan proyek agar siap di-deploy ke produksi/hosting:
```bash
npm run build
# atau jika menggunakan yarn:
yarn build
```
